# RFC-0020 — Project knowledge workspaces (digest)

**Full spec:** `docs/rfcs/0020-project-knowledge-workspaces.md`

User **project workspaces** hold code-aware knowledge for customer repos (indexing, retrieval, crafts). RFC-0060 **docs-first grounding** is orthogonal: it answers questions about **Jarvis the product** from `project/jarvis/jarvis/internal/references/`, not about the user's codebase.
