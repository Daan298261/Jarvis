# Custom models

Everyday default is Qwen3.5-9B Abliterated. If a **Qwen3.8-9B uncensored** GGUF is already installed under `models/` or the current user’s `~/.lmstudio/models`, Jarvis prefers that as the autoload default (RFC-0078).

Use the HUD ModelSelector to mark local LM Studio rows and press Play. Conversation context survives hotswap. **More** opens the full Model page. Jarvis does not download weights from the internet for this default.
