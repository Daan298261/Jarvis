# Jarvis particle-presence artwork

`humanoid.webp` and `backdrop.webp` are original Jarvis production assets generated for this repository with OpenAI's built-in image-generation tool on 2026-10-02. They do not contain artwork copied from the APEX reference site.

`humanoid-muscular.png` is a browser-compatible lossless conversion of that same original humanoid artwork. It preserves the broad-shouldered README showcase figure as an explicit second appearance without changing the locked production humanoid.
